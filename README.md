# SONG SPACE

คลังเพลงส่วนกลางธีม Dark ที่ทุกคนมีลิงก์สามารถเข้าดู ค้นหา และเพิ่มเพลงได้

## สิ่งที่มีในโปรเจกต์
- ค้นหาเพลงจาก iTunes Search API
- บันทึกเพลงลงฐานข้อมูล Supabase กลาง
- ทุกคนเห็นเพลงที่คนอื่นเพิ่มแบบเกือบเรียลไทม์
- แสดงลิงก์ค้นหาเพลงต่อบน Spotify, YouTube, Apple Music และ YouTube Music
- เพิ่มเพลงเองได้
- สุ่มเพลงจากคลังรวม
- ไม่ต้องสมัครสมาชิก: ใส่เพียงชื่อที่ใช้แสดง

## 1. สร้างฐานข้อมูล Supabase
1. ไปที่ https://supabase.com/ แล้วสร้างโปรเจกต์ใหม่
2. เปิดเมนู SQL Editor
3. วางเนื้อหาจาก `supabase/schema.sql` แล้วกด Run
4. ไปที่ Project Settings → API แล้วคัดลอก Project URL และ anon/public key

## 2. ตั้งค่าโปรเจกต์
1. แตกไฟล์ ZIP
2. คัดลอก `.env.example` เป็น `.env`
3. ใส่ค่าจริงลงใน `.env`:

```env
VITE_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

ห้ามใส่ `service_role` key ในเว็บไซต์หรือไฟล์ที่ส่งให้ผู้ใช้

## 3. ทดลองเปิดในเครื่อง
ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org/

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```bash
npm install
npm run dev
```

## 4. เผยแพร่เป็นลิงก์สาธารณะด้วย Vercel
1. อัปโหลดโฟลเดอร์โปรเจกต์ขึ้น GitHub
2. เข้า https://vercel.com/ แล้วเลือก Add New → Project
3. Import repository ที่อัปโหลดไว้
4. ใน Environment Variables เพิ่ม:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. กด Deploy
6. Vercel จะสร้าง URL สาธารณะให้ ส่งลิงก์นั้นให้ใครก็ได้

## หมายเหตุสำคัญ
- ระบบค้นหาใช้ iTunes Search API เป็นแหล่งค้นหาข้อมูลเพลง ไม่ใช่ API เดียวที่ค้นทุกแพลตฟอร์มโดยตรง ลิงก์ Spotify / YouTube / YouTube Music จะเปิดหน้าค้นหาของแพลตฟอร์มนั้น
- ผู้ใช้ทั่วไปเพิ่มเพลงได้โดยไม่ต้องล็อกอินตามที่กำหนด
- ชื่อผู้เพิ่มเป็นชื่อแสดงผลที่ผู้ใช้กรอก ไม่ใช่การยืนยันตัวตน จึงอาจตั้งชื่อซ้ำหรือแอบอ้างได้
- การลบถูกปิดไว้ในฐานข้อมูลเพื่อไม่ให้บุคคลทั่วไปลบเพลงของคนอื่น
- ก่อนเปิดให้คนจำนวนมากใช้จริง ควรเพิ่มระบบยืนยันตัวตนหรือระบบป้องกันสแปม และพิจารณาข้อจำกัดการใช้งานของบริการฐานข้อมูล
